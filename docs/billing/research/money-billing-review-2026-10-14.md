# FlowchartAI 定价商业评估：money → money-finance

日期：2026-10-14，Asia/Shanghai。范围：评估现有 Waffo 与积分草案，不改线上，不开展支付或生成测试。

**结论：200 / 2,000 / 6,000 的额度与 $9 / $19 的月付价格可作为试行方案。低模型成本证明额度有空间，但不能证明客户会买、会续费，或已经达到稳定毛利目标。暂不继续加额度，也不降低价格。主要改进应是按完整制图任务展示价值、明确积分包入口、补全成本核算。**

本轮使用 [money](/Users/tcw/.codex/skills/money/SKILL.md) 的路由逻辑，执行 [money-finance](/Users/tcw/.codex/skills/money-finance/SKILL.md) 评估。项目为已上线 Web SaaS，实际旧支付为 Creem，候选新支付为 Waffo；没有套用技能默认的 Stripe 数据来源。未取得新的真实订单、付费转化、留存、营销支出或基础设施账单，因此不估算 MRR、CAC、LTV 或净利润。

## 1. 证据与假设

- 复用 [计费草案与实际回执](billing-v1-2026-10-14.md)：5 个正常任务、9 次模型调用，外加一次平台修复。全部推理费用 $0.029566145，正常任务按拟议费率模拟扣 116 分。没有重新花钱跑模型。
- 复用一次复杂生成及三轮修改的 **107 分**样例，其中生成 23、修改 23/26/35 分；平台修复免费但要计成本。
- 本次上网核对 Waffo、OpenRouter、Eraser、Whimsical 与 MyMap 官方资料。已补取 MyMap 当前价格及其按模型/上下文消耗积分的规则；Mermaid.ai 当前定价页未返回可核实的金额，未用旧文章报价替代。
- 从技能知识库只采用两条相关经验原则：**A-1d38：按用户省事价值判断价格；A-4bf0：减少早期用户的定价决策负担。** 它们是经验框架，不能替代客户数据，也不能覆盖长上下文确实需要用量核算的事实。
- OpenRouter 假设采用 Standard，充值平台费 5.5%，该费用未包含在模型响应的推理 `usage.cost` 中；本轮未核验账户套餐或充值发票。小额充值受最低手续费影响时可能高于 5.5%，应合并充值后按实际发票分摊。Business 费率是 8%，不能默认为所有账户都适用 5.5%。
- Waffo 假设卡/数字钱包交易费 3.9% + $0.50，未计税款、提现、退款/拒付和外汇。

## 2. 成本与利润边界

以下假设所有发放积分用完；只是剩余可覆盖其他费用的金额，**不是净利润或完整毛利**。

小样本外推：`全部样本推理费用 / 正常任务模拟扣点 = 0.029566145 / 116 = $0.00025488 / 分`，已含那一次平台修复；再加 5.5% 充值费。

保守情形：沿用草案每分 $0.001 标准模型预算，额外加 50% 平台失败/取消/修复预算，再加 5.5% 充值费。50% 是运营假设，不是从样本估算的错误率。

| 产品 | 标价 / 全期积分 | 样本外推：扣推理、修复、充值费、卡交易费后剩余 | 保守全额消耗：同项费用后剩余 |
| --- | --- | ---: | ---: |
| Starter 月付 | $9 / 2,000 | $7.61，84.6% | $4.98，55.4% |
| Pro 月付 | $19 / 6,000 | $16.15，85.0% | $8.26，43.5% |
| Starter 年付 | $90 / 24,000，分月发放 | $79.54，88.4% | $48.01，53.3% |
| Pro 年付 | $190 / 72,000，分月发放 | $162.73，85.6% | $68.15，35.9% |
| 小积分包 | $10 / 1,500，永久有效 | $8.71，87.1% | $6.74，67.4% |
| 大积分包 | $30 / 5,000，永久有效 | $26.99，90.0% | $20.42，68.1% |

这里可计算的是贡献利润率：`(标价 - 模型及平台修复成本 - OpenRouter 充值费用 - Waffo 卡交易费) / 标价`。还未扣免费试用、托管、获客、售后、税款和提现。若满足 Waffo 每笔提现最低 $10 的约束、批量提现金额至少 $1,000，1% 提现费另使这里的比例减少约 0.9–1 个百分点；小额提现的有效费率更高。这是财务情景估算，没有得到实际月度净利润率。

这个区间解释了为什么可以给更充足额度，也解释了为什么不能据小样本承诺高利润。缓存、促销、完整上下文、供应商路由、生成瑕疵与免费试用量均会改变实际成本。年付还锁定一整年服务义务。额度维持当前草案，优先观察月付使用；不把年付大幅促销作为验证定价的方法。

若内部暂以 70% 的“推理/收款费用后剩余比例”为运营参考（目标，不是上线硬门）：Pro 月付的推理与平台修复平均费用需低于约 **$0.000704 / 已扣分**；Pro 年付约 **$0.000646 / 已扣分**，这还未给托管、免费用户和售后留足余量。当前样本约 $0.000255；未来付费用户是否也在这个范围内未验证。

Free 200 在当前样本比例下，全部用完连修复和充值费约 $0.054 / 注册用户。1,000 个均用完试用的注册约花 $54，尚未包含托管、邮件和支持。这是样本情景演算，不是注册预测。免费计算费用应记入获客投入；决定是否增加试用的是激活与付费结果，而不只是单次推理便宜。

## 3. 用户能否理解与选择

我上一版只列“约 80 / 260 次复杂生成”，没有同等强调修改也耗分，容易高估用户可完成的项目数量。购买页应首先给任务示例，技术费率留在说明或用量详情。

| 方案 | 价格与积分，维持草案 | 按“1 次生成 + 3 轮修改 = 107 分”样例理解 | 购买理由（待用户验证） |
| --- | --- | --- | --- |
| Free | 一次赠 200，30 天 | 完成 1 套复杂图的生成与三轮调整 | 先证明能拿到可编辑、可修改的结果 |
| Starter | $9/月，2,000/月 | 约 18 套复杂制图任务 | 个人日常使用、每月持续有需求 |
| Pro | $19/月，6,000/月 | 约 56 套复杂制图任务 | 高频制图、多项目，实际用量更大 |
| 小积分包 | $10，1,500，永久有效 | 约 14 套 | 偶尔用，不愿订阅 |
| 大积分包 | $30，5,000，永久有效 | 约 46 套 | 集中项目用量、长期储备 |

这些不是固定任务额度；图更大、对话更长、修改更多会消耗更多。也不是生成成功率或可支持的复杂度上限。收费价值是更快完成可用且可修改的图，不是低价 Token。

购买页只展示 Free / Starter / Pro 三个主选项，明确会员档位使用相同模型质量与编辑能力，区别是额度。另提供可见的“偶尔使用？一次性购买积分”入口，展开两个包；避免五张同权重卡片同时逼用户比较。

积分包单价比订阅高，换取不过期和无续费；Pro 单位额度价格优于 Starter；大包单位价格优于小包。这一梯度合理。不能为了促进订阅隐藏积分包，也不能把 Pro 写成当前并未提供的团队版或专属模型。

MyMap 是较接近我们的参照：官方明确说明生成/重写消耗积分，手动编辑、导出和演示不消耗；较长请求和较多上下文消耗更多。这支持“后台按模型和上下文算额度、前台讲清积分”的设计选择，不能证明我们的生成质量或价格优于它。其首页与定价页的免费额度有 5/20 的不一致，免费额度比较以定价页为参考且不作为本次结论依据。

我们的 Starter 月付比 Eraser Starter 低 55%，比 Whimsical Pro 低 25%，但双方附带功能不同。Pro 月付 $19 接近 Eraser Starter 的 $20；按相同年付口径，Pro 月均 $15.83 比 MyMap Pro $12 高约 32%，因此不能宣传“全面比竞品便宜”。我们的候选价值是复杂业务图可编辑、局部自然语言修改和标准 draw.io 文件交付，仍需客户认可。

**竞品实际利润率未知。** 本轮查到的是公开报价和产品规则，没有可核验的竞品推理支出、协作托管、支持、获客或财务报表。无法声称他们也有 85% 利润，也不能拿套餐的名义单次售价当利润。

$9 / $19 可以保留为试行价格，积分包补充偶尔使用。用户仍须认可复杂生成、局部修改与可编辑结果的价值；目前不能证明用户愿意支付这个价格。

## 5. 最需要验证的商业问题

**关键问题：客户是否有持续制图和修改需求，还是只在一个项目里偶尔画几张？** 若大多数用户每月不到 2,000 分，Pro 的额外额度不会带来明确升级理由；若大多数只做一次，积分包可能承担主要收入。二者不能只靠加额度解决。

新订阅 MRR、积分包一次性收入、退款和成功结果的服务成本分别记录；不能把积分包收入乘 12 当 ARR，也不能把手工会员赠送或 payment 状态记录当真实收入。

后续最小观察，不扩成复杂实验系统：

1. 免费激活：注册用户是否完成一次有效生成与一次有效修改？未完成优先查质量/等待/编辑体验。
2. 购买选择：实际订阅和积分包各有多少成功支付？不要拿点击或 Checkout 打开代替支付。
3. 每付费用户的实际成本：所有推理、平台修复与充值费，另记已扣分和发放分使用比例；不能用一个全站平均数掩盖长对话高消耗用户。
4. 持续使用：是否回来第二次制图、是否需要更多额度、是否续费；缺少这些数据时不声称已有 PMF、定价最优或稳定利润。

只需要沿用实际业务流水与基本事件，不需要多臂老虎机、额度个性化、新服务器或强制客服访谈门槛。这些观察也不构成本轮自动上线/收款的授权。

## 6. 建议与下一步

- 保留 Free 200、Starter 2,000、Pro 6,000，小包 1,500、大包 5,000；价格不降，暂不继续扩额度。
- 后台成本加权 Token 继续采用草案；前台改用“完整制图任务”示例，并在发送前解释预计扣分。
- 同一质量与编辑能力对所有档位开放；把积分包作为偶尔使用的正常选择。
- Waffo 是候选支付基础设施；商户状态与迁移完整性仍需按原计划核验。它本身不能解决用户付费意愿。
- 下一步优先做一版简洁购买页文案与额度说明供审阅；随后按授权进入本地/sandbox 实现与最小付款验证。生产发布另按用户明确范围执行。
